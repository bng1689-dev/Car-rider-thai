# Car-rider-thai

วิเคราะห์การคัดเกรดรถและหมวดบริการของแอปเรียกรถในไทย (Grab / Bolt) สำหรับรถยนต์ไฟฟ้า (BEV)

| เนื้อหา | ที่อยู่ |
|---|---|
| โปรเจกต้นทาง — data + build + template | [`ev-project/`](ev-project/) · [คู่มือ](ev-project/README.md) |
| ผลวิเคราะห์โครงสร้าง + สถาปัตยกรรมข้อมูลที่เสนอ | [`docs/DATA-ARCHITECTURE.md`](docs/DATA-ARCHITECTURE.md) |

## เริ่มใช้งาน

```bash
pip install openpyxl weasyprint
cd ev-project && python build.py
```

ผลลัพธ์ออกที่ `ev-project/outputs/` (xlsx · search.html · analysis.pdf)
