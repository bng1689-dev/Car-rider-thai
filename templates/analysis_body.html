1บทสรุปผู้บริหาร (Executive Summary)

Grab และ Bolt ใช้ ปรัชญาการจัดหมวดรถที่ต่างกันโดยสิ้นเชิง — Grab ใช้ model list (รายชื่อรุ่นที่กำหนดไว้ล่วงหน้า) เป็นเกณฑ์หลักในการจัดหมวดพรีเมียม ขณะที่ Bolt ใช้ระบบ auto-categorize จาก spec (อายุรถ ประตู ที่นั่ง ระยะฐานล้อ) ทำให้รถถูกจัดหมวดอัตโนมัติเมื่อเพิ่มเข้าระบบ ยกเว้นหมวด Comfort ที่ Bolt มี model list กำกับเช่นกัน

ในแง่ อัตราผลตอบแทนคนขับ Bolt ได้เปรียบชัดเจน เพราะหักค่าคอมมิชชันเพียง 15% (เทียบกับ Grab 25%) หมายความว่าจากค่าโดยสาร 100 บาท คนขับ Bolt ได้ 85 บาท ส่วนคนขับ Grab ได้ 75 บาท (และยังถูกหักภาษี ณ ที่จ่าย 3% เพิ่ม) แต่ Grab มีปริมาณงาน (demand) และระบบ incentive/การันตีที่หนากว่า จึงต้องพิจารณาควบคู่กับ ปริมาณงานจริง ในพื้นที่นั้นๆ

2หมวดบริการและการคัดเกรดรถ — Grab

Grab กำหนดเกณฑ์พื้นฐาน: อายุรถ ไม่เกิน 9 ปี, คนขับอายุ 22–70 ปี, สัญชาติไทย, มีใบขับขี่สาธารณะ, ไม่มีประวัติอาชญากรรม และห้ามรถกระบะ หมวดพรีเมียมทุกหมวดต้องเป็นรุ่นที่อยู่ใน MODEL LIST ที่ Grab กำหนดเท่านั้น

3หมวดบริการและการคัดเกรดรถ — Bolt

Bolt ใช้ระบบ auto-categorize — เมื่อเพิ่มรถเข้าระบบ ระบบจะจัดหมวดให้อัตโนมัติตาม spec (อายุ ประตู ที่นั่ง) เกณฑ์พื้นฐาน: อายุรถ ไม่เกิน 9 ปี, 4 ประตู, ≥4 ที่นั่ง (ไม่รวมคนขับ), ห้ามรถกระบะ จุดสำคัญคือ หมวด Comfort มี model list กำกับ และเกณฑ์อายุเข้มกว่าหมวดอื่น

5บทวิเคราะห์เชิงเปรียบเทียบ

5.1 มุมมองด้านผลตอบแทน (Driver Economics)

หากดูเฉพาะ อัตราผลตอบแทนต่อค่าโดยสาร Bolt เหนือกว่าอย่างชัดเจน (85% เทียบ 75%) แต่ตัวเลขนี้ไม่ใช่ตัวชี้ขาด เพราะรายได้สุทธิ = อัตราผลตอบแทน × ปริมาณงาน × ค่าโดยสารเฉลี่ย Grab มีส่วนแบ่งตลาดและ demand ที่สูงกว่า บวกระบบ incentive/การันตีที่หนากว่า ทำให้ในบางพื้นที่/บางช่วงเวลา รายได้รวมของคนขับ Grab อาจสูงกว่าแม้ถูกหักคอมมากกว่า

5.2 มุมมองด้านการคัดเกรดรถ (Vehicle Classification)

Grab เข้มงวดเรื่อง model list สำหรับหมวดพรีเมียม ทำให้การจัดหมวดคาดเดาได้และตรวจสอบได้ (เหมาะกับการวิเคราะห์เชิงระบบ) ส่วน Bolt ยืดหยุ่นกว่าด้วย auto-categorize แต่ความไม่โปร่งใสของ Comfort list ทำให้คนขับต้องทดลองเพิ่มรถเพื่อดูว่าเข้าหมวดใด

5.3 ข้อสังเกตเชิงระบบ (Systemic Note)

  • Grab = closed list model → ควบคุมคุณภาพรถได้แน่นอน แต่ยืดหยุ่นน้อย
  • Bolt = spec-based + hybrid list → เปิดกว้างต่อรถรุ่นใหม่ (เช่น EV จีน) เข้าหมวดได้เร็ว
  • การมีหมวด Green ของ Bolt สะท้อนกลยุทธ์ดึงดูดคนขับ EV ในช่วง EV boom ของไทย
  • ความโปร่งใสของ list มีผลต่อ การวางแผนซื้อรถ ของคนขับที่หวังขับหมวดพรีเมียม

6หมายเหตุและแหล่งอ้างอิง

ข้อจำกัดของข้อมูล: ข้อมูล Grab อ้างอิงจาก official model list ที่เผยแพร่ (ยืนยันได้) ส่วนข้อมูล Bolt บางส่วนเป็นการอนุมาน (inference) จากเกณฑ์ spec ที่เปิดเผย เนื่องจาก Bolt ไม่เปิดเผย model list ของไทยต่อสาธารณะ · ตัวเลขค่าคอมมิชชันและอัตราค่าโดยสารอาจเปลี่ยนแปลงตามนโยบายบริษัทและช่วงโปรโมชัน · ควรตรวจสอบกับแต่ละแพลตฟอร์มโดยตรงก่อนตัดสินใจ
